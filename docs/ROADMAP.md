# NOA H 1 — Build roadmap

Phase 1: API, agent contracts, scoring, risk gateway, ledger.
Phase 2: live evidence connectors with source and timestamp.
Phase 3: venture factory for offers, landing pages, onboarding and experiments.
Phase 4: subscriptions, invoicing and marketplace payouts through an appropriate payment provider.
Phase 5: market data, analytics, backtesting, risk limits and alerts.
Phase 6: durable sessions, retries, observability, evaluations, memory and multi-agent handoffs.
Phase 7: optional Android/local companion using Termux or Pydroid as an explicit execution bridge.

Definition of done: implementation + test + failure handling + audit trail + security review + rollback path.
